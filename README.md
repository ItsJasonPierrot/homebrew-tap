# homebrew-tap

Homebrew formulae for [readeasy](https://github.com/ItsJasonPierrot/readeasy) —
a terminal text-to-speech reader that makes reading easier.

## Install

```bash
brew install itsjasonpierrot/tap/readeasy
```

That single command pulls in wide-character ncurses and puts `readeasy` on your
`PATH`. Update it later with `brew upgrade readeasy`.

Prefer to tap first?

```bash
brew tap itsjasonpierrot/tap
brew install readeasy
```
